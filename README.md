# Regional Sales Performance Dashboard

# Project Overview
This project is an interactive Power BI dashboard developed to analyze regional sales performance and identify which regions should be considered for further investment based on their overall business performance.
The dashboard provides insights into **revenue, profit, quantity sold, orders, target achievement, and regional trends**, helping identify high-performing regions, underperforming regions, and potential areas for strategic investment.

# Objective
To analyze regional sales performance and identify which regions demonstrate strong potential for further investment based on **revenue, profitability, target achievement, and overall performance**.

# Tools & Technologies
* Power BI – Dashboard development and data visualization
* Power Query – Data cleaning and transformation
* DAX – KPI and performance calculations
* Excel – Data preparation and source data

# Key KPIs
The dashboard tracks the following performance indicators:
* Total Revenue
* Total Profit
* Total Quantity
* Total Orders
* Target Achievement %

# Dashboard Features
* Regional sales performance analysis
* Revenue comparison across regions
* Profitability analysis by region
* Target achievement analysis
* Monthly revenue trend
* Interactive Region filter
* Interactive Order Date filter
* Regional performance summary table
* Business insights for investment decisions

# Key Business Insights

* **Southwest** recorded the highest revenue but had a relatively lower profit margin, indicating an opportunity to improve profitability before increasing investment.
* **Northwest** achieved the highest profit margin, indicating strong profitability and efficient performance.
* **Germany and Australia** showed comparatively lower revenue and overall performance, highlighting areas that may require further analysis before additional investment.
* **France** recorded low revenue along with a very low profit margin, suggesting weaker regional performance.
* The analysis helps compare regions across multiple performance indicators and supports identifying regions with stronger potential for further investment.

# Project Workflow
1. Prepared the sales data for analysis.
2. Cleaned and transformed the data using Power Query.
3. Built the data model in Power BI.
4. Created DAX measures for key performance indicators.
5. Developed interactive visualizations to compare regional performance.
6. Analyzed revenue, profit, orders, quantity, and target achievement.
7. Derived business insights from the regional analysis.
8. Identified regions that could be considered for further investment based on their performance.
